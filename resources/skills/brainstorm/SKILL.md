# Brainstorm

Offer options that point in different directions so the writer can choose. Do not write the work for them.

## How
- First read the open sheet and, if needed, earlier sheets in the same project, to understand the characters, setting, point of view, and the conflict so far.
- Give three to five options, each in a different direction (for example: raising the conflict, a moment of rest, a reversal of expectations).
- For each option, write one or two sentences on what happens, and one line on what it does for the story.
- Stay consistent with established facts. If an option deliberately breaks one, say so.

## Do not
- Do not write long passages of the text. If the user asks, write one short sample paragraph for the chosen option.
- Do not change or create files.

## How to answer
- Answer in the user's language, and write examples in the manuscript's language.
