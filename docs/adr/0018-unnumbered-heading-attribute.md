# ADR-0018: 번호 없는 제목(서장·에필로그 등)은 시트 첫 줄 제목의 `{unnumbered}` 속성으로 표시한다

- 상태: Proposed
- 날짜: 2026-11-14
- 관련: ADR-0007(Pandoc 속성 문법), ADR-0009(책 스타일), ADR-0013(미리보기), ADR-0015(DOCX) · `src/markdown/book.rs`(`manuscript_blocks`, `UNNUMBERED`), `src/app/book_preview/layout.rs`, `src/export/epub.rs`, `src/export/docx.rs`, `src/library/preview.rs`

## 배경 (Context)

"서장", "에필로그", "막간" 같은 제목은 장 번호를 쓰지 않는다. 지금 제목 스타일(ADR-0009)은
`#`~`###` 레벨마다 접두사(`제{n}장 `)와 자동 번호를 일괄 적용하므로, 서장을 `##`로 쓰면
"제1장 서장"이 되고 뒤의 실제 1장이 "제2장"으로 밀린다.

- 레벨별로만 스타일이 갈리므로 같은 `##` 안에서 번호 있는 장과 없는 장을 구분할 방법이 없다.
- `.writer.toml`에 이름 목록을 등록하는 방식(서장·에필로그 등 글자 일치 매칭)도 검토했다.
  등록 화면·파일 형식·매칭 규칙이 늘고, 제목 글자를 조금만 달리 써도(오타, 띄어쓰기) 매칭이 깨진다.
- 시트는 사용자 데이터인 일반 `.md` 파일이므로, 표시는 원문 안에서 이뤄져야 다른 도구에서도 보인다.

## 결정 (Decision)

**시트 첫 줄 제목 끝에 Pandoc 속성 문법(ADR-0007과 같은 계열)으로 `{unnumbered}`를 붙이면
번호를 소비하지 않고 접두사도 붙지 않는다. 속성은 시트 첫 줄 제목에서만 참조한다.**

```markdown
## 서장 {unnumbered}

밤이 깊었다…
```

- 파싱: `manuscript_blocks`가 첫 블록(빈 줄 블록 제외)이 제목이면 끝의 `{unnumbered}`를
  잘라 내고 `Block::Heading.unnumbered`를 세운다. 본문 중간 제목의 `{unnumbered}`는
  파싱하지 않아 글자 그대로 렌더링된다.
- 렌더링(미리보기·PDF, ePub, DOCX 공통): `unnumbered` 제목은 `numbers[depth]`를 올리지 않고
  접두사 없이 제목만 그린다. 목차에는 접두사 없이 들어가고, 스타일(서체·크기·배치·쪽 나눔)은
  해당 레벨의 제목 스타일을 그대로 쓴다. 다음 장이 1번부터 번호를 이어간다.
- 시트 목록 카드 제목(`library/preview.rs`)에서도 속성을 지운다.
- 에디터는 원문을 그대로 보여준다(ADR-0009 원칙). 속성이 글자로 보이는 것이 정상이다.

## 결과 (Consequences)

- (+): 등록·설정 없이 원문 한 곳만 고치면 된다. 시트가 스스로 정보를 담으므로 폴더를
  복사해도 동작이 같다.
- (+): 번호 카운터를 건드리지 않아 서장 뒤의 장이 자연스럽게 1장부터 시작한다.
- (+): 파싱 지점이 `manuscript_blocks` 한 곳이고, 렌더러 3곳은 플래그 하나만 본다.
- (-): 제목 글자가 아닌 속성 기반이라, 원문을 모르는 독자가 `.md`를 열면 `{unnumbered}`가 보인다.
- (-): 첫 줄 한정이라 본문 중간에 번호 없는 소제목을 둘 수는 없다. 그 경우는 `####`(굵은 문단)를 쓴다.
- 후속(TODO): 편집 화면에서 첫 줄 속성을 흐리게 표시(마크업 스팬)는 하지 않았다.

## 대안 (Alternatives)

| 대안 | 기각 사유 |
| --- | --- |
| `.writer.toml`에 번호 없는 제목 이름 등록(글자 매칭) | 등록 UI·파일 형식이 늘고, 제목 글자 매칭이라 오타·변형에 깨진다. 같은 이름의 장을 일부러 번호 없이 쓰려면 반대로 못 쓴다 |
| 모든 제목에서 `{unnumbered}` 참조 | 본문 중간 제목은 번호·목차 구조의 일부라 예외를 넓히면 번호 체계가 예측 어려워진다. 필요하면 그때 확장한다 |
| `Numbering::None` 스타일 추가 | 스타일은 레벨 단위라 서장만 골라 적용할 수 없다 |
| 에디터에서 제목별 드롭다운으로 스타일 지정 | 줄 단위 원문 버퍼(ADR-0011) 구조와 맞지 않고, 원문에 표시가 남아야 다른 도구와 어긋나지 않는다 |
