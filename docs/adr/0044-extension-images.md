# ADR-0044: 확장은 라이브러리 안의 그림 파일만 `g.newImage`로 읽어 LÖVE식 `g.draw`로 그린다

- 상태: Proposed
- 날짜: 2026-10-23
- 관련: ADR-0026(Lua 확장, sandbox), ADR-0039(폴더 확장), ADR-0041(메모 첨부파일), ADR-0042·0043(그리기·효과) · `src/extension/image.rs`, `src/extension/canvas.rs`(`Shape::Image`, `LuaImage`, `LuaQuad`), `src/extension/render.rs`, `src/extension/svg.rs`, `src/export/pdf.rs`, `resources/skills/extension/references/examples/photo-frame.md`

## 배경 (Context)

원고에 넣은 사진을 꾸미고 싶다(폴라로이드 테두리, 기울이기, 그림자, 둥근·원형 자르기, 사진 위 이름표). 원고 이미지 속성(ADR-0007)에
꾸밈을 몇 가지 더하는 길도 있지만, 확장은 꾸미는 방식을 마음대로 만들 수 있고 ADR-0043의 그림자·자르기와 바로 이어진다. 확장은
지금까지 파일에 전혀 닿지 못했다. 어시스턴트는 그림 파일을 만들 수 없으므로, 그림은 사용자가 넣은 것만 쓴다.

## 결정 (Decision)

**`g.newImage(path)`는 라이브러리 루트 기준 경로(폴더 확장은 자기 폴더 먼저)의 PNG·JPEG·GIF·WebP만 읽고, `g.draw(img[, quad], x, y, r, sx, sy, ox, oy)`·
`g.newQuad`·`img:getDimensions()`·`img:setFilter("nearest")`는 LÖVE를 따른다.**

- 읽기 규칙(`image::resolve`): 절대 경로와 `..`은 받지 않고, 실제 경로(링크를 따라간 것)가 라이브러리 안이어야 한다. 확장자는 그림만, 파일은 32MB까지.
  읽을 곳은 `Package.images`(라이브러리에서 읽은 확장만)로 넘긴다. 확장은 픽셀을 그릴 뿐 밖으로 보낼 길이 없다.
- 캐시: (경로, 바뀐 때, 크기)로 32개까지. 화면용 픽셀은 긴 변 2048px로 줄이고, 원래 파일은 PDF·SVG에 그대로 넣는다. 읽는 시간은 호출 시간 제한(0.1초)에서 뺀다.
- 모양: `Shape::Image { image, src, transform, opacity, smooth }`. `transform`은 그림 픽셀(원래 크기)을 캔버스로, `src`는 보이는 칸이다.
  색은 섞지 않고 지금 색의 투명도만 따른다(LÖVE의 기본 흰색과 달리 여기 기본 색은 테마 글자색이라서).
- 그리기: vello 그림 칠로 `src` 사각형을 채운다. 자르기·그림자·섞기가 그대로 걸린다. 내보내기: PDF는 원래 파일을 krilla 그림으로(칸 밖은 자른다),
  SVG(ePub)는 data URI의 `<image>`를 안쪽 `<svg>`로 자른다. DOCX는 그림이 있으면 SVG 없이 PNG만 넣는다(파일을 두 번 넣지 않도록).
- 스킬: 그림은 사용자가 가진 것만 쓰라고 적고, 예제 `photo-frame`(폴라로이드·둥근·원형, 꽉 채워 자르기)을 둔다.

## 결과 (Consequences)

- (+): 사용자의 사진을 확장으로 꾸민다. 폴더 확장은 스프라이트·무늬를 들고 다닌다(플레이 창 게임).
- (-): 확장이 라이브러리 안의 그림을 읽을 수 있다(남이 쓴 확장도). 쓰기·목록·네트워크가 없어 그리기 말고는 쓸 데가 없다.
- (-): 그림 파일을 바꿔도 그 블록은 확장이나 인자가 바뀔 때까지 옛 그림을 보일 수 있다(캐시는 바뀐 때로 새로 읽는다).
- (-): 블록 인자에 적는 경로는 라이브러리 기준이라, 시트의 이미지 경로(메모는 `Notes/` 기준, 프로젝트는 프로젝트 기준)와 다르다.

## 대안 (Alternatives)

| 대안 | 기각 사유 |
| --- | --- |
| 원고 이미지 속성(`{.shadow .rounded}`) | 꾸밈이 정해진 몇 가지뿐이다. 따로 할 수 있고 서로 막지 않는다 |
| 폴더 확장 안의 그림만 | 사용자의 사진을 꾸밀 수 없다(원래 바람) |
| 색으로 그림을 물들인다(LÖVE) | 기본 색이 테마 글자색이라 아무 설정 없이 그린 사진이 검게 된다 |
