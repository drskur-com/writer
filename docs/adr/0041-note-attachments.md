# ADR-0041: 메모의 첨부파일은 `Notes/Attachments`에 두고 `Notes/` 기준 경로로 적는다

- 상태: Proposed
- 날짜: 2026-10-23
- 관련: ADR-0021(경로 해석), ADR-0022(프로젝트 기준 경로) · `src/library/book.rs`, `src/library/images.rs`, `src/library/meta.rs`, `src/app/insert_image.rs`

## 배경 (Context)

ADR-0022는 프로젝트 시트의 이미지를 `<Project>/Extras/Attachments`에 복사하고 프로젝트 기준
경로로 적게 했지만, 메모는 결정에서 뺐다. 메모에는 첨부파일 그룹이 없어 고른 파일의 절대 경로를
그대로 적었다.

- 원본 파일을 옮기거나 지우면 메모의 그림이 깨진다.
- 절대 경로는 라이브러리를 옮기거나 다른 Mac(iCloud 등)에서 열면 깨진다.
- 웹 주소 이미지는 내려받지 않아 오프라인에서 보이지 않는다.

## 결정 (Decision)

**메모의 첨부파일은 메모 그룹 모두가 함께 쓰는 파일 그룹 `Notes/Attachments`에 `<ULID>.<확장자>`로
두고, `Notes/` 기준 경로(`Attachments/<ULID>.png`)로 적는다.**

- 첨부 함수(`add_attachment`·`attach_bytes`)는 기준 폴더(프로젝트 폴더나 `Notes/`)를 받는다.
  `attachments_dir`가 기준 폴더에 맞는 첨부파일 그룹을 돌려준다. 그룹은 처음 첨부할 때 만든다
  (표시 이름 "첨부파일", 클립 아이콘, 파일 그룹).
- 이미지 삽입 대화상자는 메모에서도 "첨부파일" 탭을 보이고, 웹 이미지를 내려받아 첨부한다.
- `resolve_image_path`는 프로젝트 폴더를 모르면 시트 폴더가 든 프로젝트 폴더나 `Notes/`를 기준
  폴더로 쓴다. 메모를 다른 그룹(하위 그룹 포함)으로 옮겨도 같은 그림을 찾는다.
- `Notes/Attachments`는 예약 그룹이다. 옮길 수 없고, 이름을 바꾸면 표시 이름만 바뀐다. 메모
  섹션 바로 아래에는 `Attachments`라는 시트 그룹을 만들거나 그 이름으로 바꿀 수 없다(` 2`를 붙인다).
- 예전에 적은 절대 경로는 고쳐 쓰지 않는다. 그대로 열린다.

## 결과 (Consequences)

- (+): 메모 그림이 라이브러리 안에 남아 원본을 지워도, 라이브러리를 옮겨도 이어진다.
- (+): 프로젝트와 같은 규칙(기준 폴더 + 첨부파일 그룹)이라 코드가 한 갈래다.
- (-): 메모 그룹을 지워도 그 메모가 쓰던 첨부파일은 남는다. 그룹별 폴더가 아니어서 어떤 그림을
  누가 쓰는지 파일 위치로는 알 수 없다.
- (-): 이 결정 전에 사용자가 `Notes/Attachments`라는 시트 그룹을 만들어 두었다면 처음 첨부할 때
  파일 그룹으로 바뀌어 그 안의 메모가 목록에서 보이지 않는다(파일은 남는다).

## 대안 (Alternatives)

| 대안 | 기각 사유 |
| --- | --- |
| 메모 그룹마다 첨부 폴더(`Notes/<그룹>/Attachments`) | 메모를 다른 그룹으로 옮기면 그림을 함께 옮기거나 경로를 고쳐 써야 한다. 메모는 그룹 사이를 자주 오간다 |
| 라이브러리 맨 위 폴더(`<라이브러리>/Attachments`) | 메모 섹션 밖이라 사이드바에서 보이지 않고, 섹션 구조(`Notes`·`Projects`)에 세 번째 자리가 생긴다 |
| 숨김 폴더(`.writer/attachments`) | Finder·다른 편집기에서 찾기 어렵고, 사용자가 첨부파일을 둘러볼 수 없다 |
| 절대 경로 유지 | 원본 이동·라이브러리 이동·다른 기기에서 깨진다 |
