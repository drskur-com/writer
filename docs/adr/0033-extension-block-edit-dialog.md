# ADR-0033: 확장 블록은 삽입 대화상자의 편집 모드로 고치고, 캔버스를 눌러도 커서가 블록으로 들어가지 않는다

- 상태: Proposed
- 날짜: 2026-10-23
- 관련: ADR-0026(Lua 확장), ADR-0032(호버·클릭), ADR-0008(이미지 편집 대화상자) · `src/app/insert_extension.rs`(`ExtensionPicker::edit`, `EditBlock`, `replace_extension_block`), `src/app/editor_extension.rs`(`interactive`, `block_range`), `src/app/editor_link.rs`

## 배경 (Context)

확장 블록의 인자를 바꾸려면 커서를 블록에 넣어 펜스를 펼치고 `key: value` 줄을 직접 고쳐야 했다. 인자 이름과 뜻은 확장
앞머리에만 있어 사용자는 무엇을 쓸 수 있는지 모른다. 삽입 대화상자는 이미 앞머리로 인자 칸·설명·미리보기를 보이지만
넣기만 한다. 앞으로 인라인 확장과 블록 원자화(펜스를 보이지 않음)도 편집할 곳이 있어야 한다.

## 결정 (Decision)

**삽입 대화상자에 편집 모드를 둔다. 블록 캔버스를 누르면 커서를 옮기지 않고, 두 번 누르거나 ⌘와 누르면 그 블록의
편집 대화상자를 연다.**

- 편집 모드(`ExtensionPicker::edit`): 확장 목록을 숨기고 블록의 확장 하나만 다룬다(확장 파일이 없거나 읽지 못해도 연다).
  - 칸의 처음 값은 블록 인자다(같은 인자가 여럿이면 마지막 것). 앞머리에 없는 블록 인자도 칸으로 보인다. "블록 값으로 되돌리기"는
    이 값으로 돌아간다.
  - "원문 편집": 블록 글 전체를 고치는 입력창으로 바꾼다. 미리보기는 그 글의 인자로 그리고, 저장하면 그 글을 그대로 쓴다.
    인자 칸으로 만들면 사라지는 줄(설명 줄, 같은 인자의 앞 줄)을 지키거나, 확장 이름을 바꿀 때 쓴다.
  - 저장: 대화상자를 연 에디터가 그대로이고 블록 범위의 글이 열 때와 같을 때만 쓴다(이미지 편집과 같다). 블록 전체를
    `block_text(name, args)`(또는 원문)로 바꾸는 한 번의 편집이고, 커서는 그대로 둔다(`replace_range_keeping_selections`).
- 미리보기도 누를 수 있다: 에디터 블록의 마우스 처리(`interactive`)를 일반화해 대화상자 미리보기에 붙이고, `click`이 돌려준 값을
  블록이 아니라 인자 칸에 쓴다(칸이 없으면 더한다). 사용자는 미리보기를 눌러 값을 골라 보고 저장할 때 한 번에 쓴다. 삽입할
  때도 같다.
- 여는 곳: 캔버스 두 번 누르기, 캔버스 ⌘-클릭, 펼친 펜스 글 ⌘-클릭(링크가 아니면), 메뉴 Extensions → 블록 편집…(커서가 블록 안).
- 캔버스를 누르면 커서가 블록으로 들어가지 않는다(`prevent_default`). 그래서 누르기만으로 펜스가 펼쳐져 캔버스가 밀리지 않고,
  두 번 누르기가 같은 캔버스에 닿는다. 펜스 글은 화살표 키로 들어가 지금처럼 고칠 수 있다.

## 결과 (Consequences)

- (+): 인자의 뜻을 보며 고치고, 결과를 미리보기로 바로 본다. 되돌리기 한 번으로 돌아간다.
- (+): 인라인 확장·블록 원자화가 같은 대화상자를 편집 경로로 쓴다.
- (-): 인자 칸으로 저장하면 블록을 새로 쓴다(`` ``` `` 펜스, 칸 순서). 설명 줄이나 `~~~` 펜스는 원문 편집으로만 지킨다.
- (-): 캔버스에서 끌어 블록 너머까지 고르는 선택은 시작할 수 없다(펜스 글이나 다른 줄에서 시작한다).
