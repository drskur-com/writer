# ADR-0005: 그룹 메타는 그룹 폴더의 `.writer.toml`에 둔다

- 상태: Accepted
- 날짜: 2026-10-20
- 관련: PLAN.md §3.2, §3.3 · Supersedes ADR-0003(파생 데이터 위치 항목) · `src/library.rs` (`GROUP_META_FILE`, `read_group_meta`, `write_group_meta_if_absent`)

## 배경 (Context)

ADR-0003은 "순서/즐겨찾기/인덱스 같은 파생 데이터는 `<Library>/.writer/`에 두는 재생성 가능한 캐시"로 정했다.
사이드바에 그룹 아이콘·표시 이름·시트 수동 순서를 붙이면서(커밋 `7ddb9e6`) 다음이 드러났다.

- 아이콘·표시 이름·시트 순서는 **사용자가 직접 정한 값**이라 본문에서 재생성할 수 없다. 캐시로 취급하면 지웠을 때 데이터가 사라진다.
- 그룹은 디렉터리라서 시트처럼 frontmatter에 메타를 넣을 곳이 없다.
- 사용자가 Finder/탐색기나 동기화 도구로 그룹 폴더를 옮기거나 이름을 바꿔도 메타가 따라가야 한다. 중앙 파일에 경로 키로 두면 이때 연결이 끊긴다.

## 결정 (Decision)

**그룹 메타는 각 그룹 디렉터리 안의 `.writer.toml`에 둔다. `<Library>/.writer/`에는 라이브러리 마커와
재생성 가능한 캐시(인덱스 등)만 둔다.**

- 스키마(`schema` 필드 없음, 모든 키 선택):
  ```toml
  icon = "inbox"          # Lucide 아이콘 이름 (ADR-0004)
  title = "받은 편지함"     # 표시 이름, 없으면 폴더 이름
  sheets = ["b.md", "a.md"] # 시트 파일명 순서
  ```
- 읽기: 파일이 없거나 파싱에 실패하면 기본값으로 동작한다(에러로 막지 않음).
- 정렬: `sheets`에 나열된 파일을 그 순서대로 앞에 두고, 나열되지 않은 파일은 이름순으로 뒤에 붙인다. 목록에만 있고 실제로 없는 파일은 무시한다.
- 생성: 기본 그룹(Inbox, 샘플 프로젝트)은 초기화 시 파일이 없을 때만 만든다(멱등, 사용자 편집을 덮어쓰지 않음).
- 메타 위치 기준은 "누가 소유하고 동기화돼야 하는가"다:

  | 위치 | 담는 것 |
  | --- | --- |
  | 시트 frontmatter (예정) | 시트 고유 메타: keywords, goal |
  | `<Group>/.writer.toml` | 그룹 메타: icon, title, 시트 순서 |
  | `<Library>/.writer/` | 마커, 인덱스, 캐시 (지워도 데이터 손실 없음) |

## 결과 (Consequences)

- (+): 그룹 폴더를 통째로 옮기거나 복사·동기화해도 아이콘·순서가 유지된다.
- (+): `.writer/`는 다시 순수 캐시가 되어, 삭제·동기화 충돌 시 재생성으로 복구된다.
- (+): 메타가 깨져도 기본값으로 열려 라이브러리 전체가 막히지 않는다.
- (-): 그룹 폴더마다 숨김 파일이 하나씩 생긴다(다른 마크다운 앱/ git에서 보임).
- (-): 앱 밖에서 시트 파일 이름을 바꾸면 `sheets` 목록에서 빠져 이름순 꼬리로 밀린다. 파일 감시(M1)에서 rename을 감지하면 목록을 갱신한다.
- (-): 여러 기기에서 같은 그룹 순서를 동시에 바꾸면 `.writer.toml` 동기화 충돌이 날 수 있다(M9 충돌 처리 대상).
- 후속(TODO):
  - 드래그 정렬·이름 변경·이동 시 `.writer.toml` 쓰기 (M3), 원자적 저장(temp+rename) 적용
  - 하위 그룹 순서(`groups = [...]`)와 펼침 상태 위치 결정 — 펼침 상태는 머신 로컬이므로 `config.toml` 쪽이 후보
  - 스키마 버전이 필요해지면 `schema_version` 키 추가

## 대안 (Alternatives)

| 대안 | 기각 사유 |
| --- | --- |
| 중앙 `<Library>/.writer/library.toml`에 경로 키로 저장 (ADR-0003 원안) | 앱 밖에서 폴더를 옮기거나 이름을 바꾸면 메타가 끊긴다. 캐시와 사용자 데이터가 섞여 `.writer/`를 안전하게 지울 수 없다 |
| SQLite 인덱스에 저장 | 위와 같고, 사람이 읽거나 고칠 수 없으며 동기화 시 바이너리 충돌 |
| 폴더 이름 접두어로 순서/아이콘 표현 (`01_`, 이모지) | 사용자에게 보이는 이름을 오염시키고 아이콘 표현이 제한적 |
| 그룹 안의 인덱스 시트(`_index.md`) frontmatter | 시트 목록에 가짜 시트가 섞이고, 다른 앱에서 일반 문서로 보인다 |
