# ADR-0014: 시트는 개별로 옮기고 이동 위치에 따라 접합을 유지·해제·추가한다

- 상태: Proposed
- 날짜: 2026-10-21
- 관련: ADR-0012, ADR-0013 · `src/library/meta.rs`, `src/app/sheet_list.rs`, `src/app/library_ops.rs`
- Supersedes ADR-0012의 이동 단위·드래그 미리보기·놓일 자리 표시 결정

## 배경 (Context)

ADR-0012는 접합한 시트를 묶음째 옮기고, 접합 내부에는 놓을 수 없도록 했다.
이 방식으로는 접합 내부의 시트 순서를 바꾸거나 시트 하나만 꺼내고 넣을 때 먼저 접합을 해제해야 한다.
접합은 유지하면서 시트 하나를 이동할 수 있어야 한다.

## 결정 (Decision)

**접합 여부와 관계없이 드래그한 시트 하나만 옮긴다. 이동한 시트의 접합은 목적 위치에 따라 정하고, 원래 묶음에 남은 시트의 접합은 유지한다.**

- 같은 접합 내에서 순서를 바꾸면 이동한 시트와 나머지 시트 모두 접합을 유지한다. 묶음의 첫 위치나 마지막 위치로 옮기는 경우도 같다.
- 접합 밖으로 옮기면 이동한 시트만 접합을 해제한다. 첫·중간·마지막 시트를 빼도 남은 시트들은 원래 묶음으로 이어진다. 하나만 남으면 독립 시트가 된다.
- 외부 시트를 접합한 두 시트 사이에 넣으면 그 접합에 합류한다. 다른 접합에서 가져온 시트도 같다.
- 다른 묶음의 바깥 경계나 독립 시트 사이에 놓으면 접합하지 않는다. 같은 접합 내의 재정렬과 구분한다.
- 위로 옮기면 대상 카드 앞, 아래로 옮기면 대상 카드 뒤에 놓는다. 접합 내부에서도 놓일 자리 표시를 보여 준다.
- 드래그 미리보기는 움직이는 시트 하나의 이름만 보여 준다.
- 복수 선택된 시트는 이동 후 목록 순서로 다시 정렬한다. 이후 미리보기·컴파일에서도 그 순서를 쓴다.
- 접합 소속은 이동 중에만 임시 번호로 보존한다. 저장 형식은 기존 그룹 `.writer.toml`의 `sheets`·`glued`를 유지하고, 저장 실패 시 순서와 접합을 함께 되돌린다.
- 수동 정렬 그룹에서만 이동·접합을 다룬다는 제한, 접합·해제 메뉴, 미리보기·컴파일의 범위 규칙은 ADR-0012를 따른다.

예시에서 대괄호는 접합 묶음이다.

| 이동 전 | 이동 | 이동 후 |
| --- | --- | --- |
| `[a b c] d` | a를 c 뒤로 | `[b c a] d` |
| `[a b c] d` | b를 d 뒤로 | `[a c] d b` |
| `[a b c] d` | d를 a와 b 사이로 | `[a d b c]` |
| `[a b c] d` | d를 a 앞으로 | `d [a b c]` |
| `[a b] [c d]` | b를 c와 d 사이로 | `a [c b d]` |

## 결과 (Consequences)

- (+): 접합을 먼저 해제하지 않고 내부 순서를 바꾸거나 개별 시트를 꺼내고 넣을 수 있다.
- (+): 이동한 시트를 제외한 나머지 접합은 유지된다. 메타 형식 변경이나 기존 데이터 변환이 필요 없다.
- (-): 묶음 전체를 한 번의 드래그로 옮기는 동작은 제공하지 않는다.
- (-): 다른 묶음에 합류할 때는 묶음 바깥 경계가 아닌 내부의 시트 사이에 놓아야 한다.

## 대안 (Alternatives)

| 대안 | 기각 사유 |
| --- | --- |
| 접합 묶음째 이동 유지 | 접합 내 재정렬과 개별 시트 이동을 할 수 없다 |
| 이동하면 항상 접합 해제 | 같은 묶음 안에서 순서만 바꾸어도 접합을 다시 해야 한다 |
| 접합한 시트에 인접하면 항상 합류 | 묶음 밖에 독립 시트로 놓을 수 없다 |
