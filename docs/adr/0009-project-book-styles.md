# ADR-0009: 책 스타일은 프로젝트 `.writer.toml`의 `[styles.<대상>]`에 두고, 다른 프로젝트에서는 값을 복사해 가져온다

- 상태: Proposed
- 날짜: 2026-10-20
- 관련: ADR-0005, ADR-0006, PLAN.md M7(스타일 테마) · `src/library/style.rs`, `src/app/book_style.rs`, `src/app/editor.rs`

## 배경 (Context)

본문·부/장/절 제목의 서체·줄 간격·정렬·들여쓰기·여백을 정하는 "책 스타일"이 필요하다.
이 값은 에디터 렌더링과 내보내기(ePub·PDF 등)가 함께 쓴다. 다른 프로젝트의 스타일을 가져다 쓰는 방법도 필요했다.

여러 프로젝트가 스타일 하나를 함께 쓰는 "공유 스타일"(`<Library>/Styles/<ULID>.toml` + 프로젝트의 참조)도 검토했다.
다음 문제 때문에 지금은 하지 않기로 했다.

- 프로젝트 폴더만 복사하면(Finder, 다른 기기) 참조가 끊기고 스타일이 기본값으로 바뀐다.
- 끊김을 막으려고 사본을 함께 두면, 공유 스타일을 고칠 때 연결된 프로젝트 파일을 모두 다시 써야 해서 동기화 충돌과 일부만 갱신되는 문제가 생긴다.
- 삭제 확인, 사용 중인 프로젝트 수, 공유 스타일 편집 화면, `.writer` 내보내기에 스타일 파일 담기가 모두 따라 필요해진다.

## 결정 (Decision)

**책 스타일은 프로젝트 루트 `.writer.toml`의 `[styles.<대상>]` 표에 둔다. 다른 프로젝트의 스타일은 값을 그대로 복사해 가져온다.**

- 대상과 파일 키(바꾸지 않는다): `body`, `title:part`, `title:chapter`, `title:section`.
- ATX 제목 대응: `#` = 부, `##` = 장, `###` = 절. `####` 이하는 제목 대상이 없다.
- 값(모두 선택, 길이 단위 em = 본문 글자 크기 대비):
  ```toml
  [styles.body]
  font = "Noto Serif KR"   # 에디터 서체. 없으면 앱 설정의 에디터 서체
  embed_font = false       # 내보낼 때 서체 파일을 넣는지(아니면 리더 기본 서체)
  line_height = 1.6
  align = "justify"        # left | center | right | justify
  first_line_indent = 1.0
  space_after = 0.0        # 본문에서는 문단 사이 간격

  [styles."title:chapter"]
  placement = "inline"     # inline(본문 첫머리) | page(별도 제목 페이지) | hidden(제목 숨김)
  page_break = true        # 새 페이지에서 시작(page는 늘 새 페이지)
  prefix = "제{n}장 "       # 제목 앞에 붙는 글. {n}은 자동 번호
  font_size = 1.4          # 본문 대비 배율
  font_weight = 700        # 300~900
  space_before = 3.0
  vertical_align = "center" # page일 때 세로 위치: top | center | bottom
  in_toc = true            # 목차에 포함. 빼면 번호를 매기지 않고 접두사도 붙이지 않는다
  ```
- 제목 기본 배치: 부는 별도 제목 페이지(세로 가운데), 장은 새 페이지 첫머리, 절은 앞 내용에 이어서. 제목 굵기는 700, 접두사는 없음.
- 제목 편집 화면은 epubly 스타일 화면과 같은 순서·조건을 따른다: 배치 → 새 페이지에서 시작(별도 페이지가 아닐 때) → 목차에 포함 → 접두사(목차에 포함할 때) → 서체·크기·굵기·줄 간격·정렬 → 세로 위치(별도 페이지일 때) → 앞 여백(본문 첫머리이고 이어서 놓일 때) → 뒤 여백(본문 첫머리일 때). 미리보기는 쪽 나눔 위치를 보인다.
- 파일에는 사용자가 바꾼 값만 쓴다. 빠진 값은 대상별 기본값(`StyleTarget::defaults`)으로 채운다. 모두 기본값이면 `[styles]` 표를 지운다. 숫자는 소수 둘째 자리로 맞춰 쓴다.
- 우선순위: 프로젝트 스타일 → 앱 설정(`Prefs.editor_font`) → 대상 기본값. 제목의 서체·서체 포함은 정하지 않으면 본문을 따른다.
- 책 스타일은 프로젝트 시트에만 쓴다. 메모(프로젝트 밖 시트)는 대상 기본값도 쓰지 않고 앱 설정 서체에 왼쪽 정렬, 들여쓰기·블록 여백 없이 보인다. 메모 그룹별 스타일은 나중에 따로 정한다.
- 본문 서체는 **에디터 서체**다. 내보낼 때 서체를 넣으면(`embed_font = true`) 에디터와 책의 서체가 같아지고,
  넣지 않으면 책은 리더 기본 서체로 보인다. 미리보기는 내보낸 책 기준으로 그린다(넣지 않으면 시스템 서체).
- 서체를 정하지 않은 채 서체 포함을 켜면 지금 쓰는 서체(설정의 에디터 서체)를 프로젝트에 적어 넣는다.
  설정의 에디터 서체는 컴퓨터마다 달라 그대로 두면 내보내는 곳마다 결과가 달라지기 때문이다.
- 에디터는 서체, 줄 간격, 제목 크기·굵기에 더해 정렬·첫 줄 들여쓰기·여백도 반영한다(ADR-0010).
  쪽 나눔은 에디터에 "여기서 페이지가 나뉩니다" 표시로 보인다(ADR-0010). 제목 배치(별도 페이지·숨김)와 접두사는 내보낼 때만 쓴다(에디터는 원문을 그대로 보인다).
- 편집 화면은 에디터 자리에 연다(모달 아님). 실수로 닫히지 않게 하고, 값을 바꾸면 바로 저장한다. 폼과 미리보기를 나란히 두려고 이 화면에서는 시트 목록 칸을 숨긴다.

## 결과 (Consequences)

- (+): 프로젝트 폴더만 옮겨도 스타일이 따라간다. 참조나 끊김 처리가 없다.
- (+): 스타일 묶음이 하나의 타입(`Styles`)이고, 값 해석은 `Styles::resolve` 한 곳이다. 편집 화면은 저장 위치를 모른다. 나중에 공유 스타일을 더해도 이 세 곳만 늘리면 된다.
- (-): 여러 책의 스타일을 한 번에 바꿀 수 없다. 프로젝트마다 다시 가져와야 한다.
- 후속(TODO):
  - 내보내기(M7)에서 `ResolvedStyle`을 CSS·typst로 옮기기, `embed_font` 처리
  - 새 프로젝트 대화상자에서 스타일을 가져올 프로젝트 고르기
  - 필요해지면 공유 스타일: `[style] shared = "<ULID>"` 참조 + `<Library>/Styles/<ULID>.toml`(같은 `Styles` 스키마). 기존 `[styles.*]`는 그대로 고유 스타일로 남는다.

## 대안 (Alternatives)

| 대안 | 기각 사유 |
| --- | --- |
| 공유 스타일 참조만 둠 | 폴더 복사 시 연결이 끊긴다. 지금 필요한 것보다 화면·규칙이 크게 는다 |
| 공유 스타일 + 프로젝트 사본 | 편집할 때마다 연결된 프로젝트를 모두 다시 써야 해서 동기화 충돌·일부만 갱신되는 문제 |
| 앱 설정(`config.toml`)에 저장 | 머신 로컬이라 프로젝트와 함께 옮겨지지 않는다 |
| `<Library>/.writer/`에 저장 | 지워도 되는 캐시만 두는 곳이다(ADR-0005) |
| 편집을 모달 대화상자로 | 바깥 클릭·Esc로 닫혀 편집을 잃기 쉽고, 미리보기를 둘 폭이 좁다 |
