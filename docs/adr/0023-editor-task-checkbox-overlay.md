# ADR-0023: 에디터의 할 일 항목은 기호 위에 체크 상자를 겹쳐 그리고, 누르면 원문의 `[ ]`·`[x]`만 바꾼다

- 상태: Proposed
- 날짜: 2026-10-22
- 관련: ADR-0006, ADR-0008, ADR-0017 · `src/app/editor_task.rs`, `src/markdown/mod.rs`(`task_marker`, `SpanKind::TaskDone`), `vendor/gpui-base/src/input/base/element_writer.rs`(`prepaint_line_overlays`), `vendor/gpui-base/src/input/editor/writer.rs`(`set_line_overlays`, `replace_range_keeping_selections`), `docs/patches/gpui-base-0.8.0-line-overlay.patch`

## 배경 (Context)

GFM 할 일 항목(`- [ ] 일정`·`- [x] 일정`)은 미리보기·내보내기에서 ☐·☑로 그리지만, 에디터에는 흐린
`- [ ] ` 글자만 보였다. 체크하려면 `[ ]` 안에 `x`를 직접 써야 했다.

- 시트는 일반 `.md`다. 저장 표기는 표준(GFM) 그대로여야 한다.
- gpui-base 0.8.0의 인라인 토큰(원문 범위를 칩으로 그림)은 한 줄·여러 줄 입력에만 있고 에디터 모드
  (`EditorMode`)에서는 막혀 있다(`UnsupportedMode`). 토큰은 문서 모델에 붙는 것이라 원문과 따로 맞춰야 한다.
- 줄 블록(ADR-0008)은 줄 **아래**에 그린다. 기호 자리(줄 안)에는 그릴 수 없다.

## 결정 (Decision)

**gpui-base에 줄 오버레이를 더한다. 줄 안의 바이트 범위 위에 앱이 요소를 겹쳐 그린다.** 원문과 배치는
바꾸지 않는다.

- API: `EditorState::set_line_overlays(ranges, render, cx)`.
  - `ranges(row, line) -> Vec<Range>`: 보이는 줄마다 덮을 범위(줄 안 바이트)를 정한다. 매 프레임 보이는 줄에만
    부르므로 줄 글자만 본다.
  - `render(LineOverlayContext { line, text, range, size })`: 덮은 글자 폭 × 그 행 높이 크기로 그린다. 글자 위에
    그리므로 불투명한 배경을 칠한다.
  - 한 행 안에 있는 범위만 그린다. 접힌 줄(이미지·표)에는 그리지 않는다.
  - **선택(커서 포함)이 닿은 줄에는 그리지 않는다.** 그 줄은 원문 글자가 보여 바로 고칠 수 있다(ADR-0008·0017의
    "커서가 닿으면 원문"과 같은 동작). 배치를 바꾸지 않으므로 커서가 들어가고 나와도 글이 밀리지 않는다.
  - 그리는 순서는 글자 → 인라인 토큰 → 오버레이 → 줄 블록 → 캐럿이다.
- API: `EditorState::replace_range_keeping_selections(range, text, window, cx)`: 되돌리기 가능한 편집 하나로
  범위를 바꾸고, 선택은 제자리에 둔다(편집 뒤쪽이면 길이 차만큼 민다). 체크할 때 캐럿이 그 줄로 가면 오버레이가
  빠지므로 필요하다.
- 앱(`editor_task.rs`)은 `markdown::task_marker`로 할 일 줄을 판정한다.
  - 글머리표 목록은 `- [ ] ` 전체를, 번호 목록은 번호를 남기고 `[ ] `만 덮는다. 인용 안의 할 일은 보지 않는다.
  - 체크 상자는 줄 높이의 55%(12–18px) 정사각형이다. 완료는 강조색 바탕에 체크 아이콘이다.
    덮은 범위의 오른쪽 끝(항목 글 바로 앞)에 상자 한 변의 40%만큼 띄워 둔다. 글머리표 자리는 비운다.
  - 누르면(`mouse down`) `prevent_default`로 캐럿을 옮기지 않고, 그 자리의 ` `↔`x` 한 글자만 바꾼다.
    누른 사이 줄이 바뀌어 같은 자리에 체크 상자가 없으면 아무것도 하지 않는다.
- 완료한 항목의 글은 취소선과 흐림으로 보인다(`SpanKind::TaskDone`, 마크업 표시).

## 결과 (Consequences)

- (+): 에디터에서 할 일을 눌러 체크한다. 파일은 표준 GFM 그대로다.
- (+): 배치를 바꾸지 않아 줄바꿈·커서 이동·클릭 판정·스크롤이 그대로다. 오버레이가 없는 문서는 비용이 없다.
- (+): 되돌리기로 체크를 되돌린다.
- (-): gpui-base 패치가 늘었다(`docs/patches/gpui-base-0.8.0-line-overlay.patch`, 5파일 +241/−1). gpui-base를
  올릴 때 다른 패치 다음에 적용한다.
- (-): 줄 글자만 보므로 코드 블록 안의 `- [ ] ` 줄에도 체크 상자를 그린다(ADR-0006과 같은 한계).
- (-): 오버레이는 배경을 칠해 글자를 가리므로, 그 범위의 검색 강조는 커서가 들어가야 보인다.
- (-): 체크 상자 크기는 기호 글자 폭과 무관하게 정했다. 서체가 아주 좁으면 상자가 덮은 범위보다 클 수 있다.

## 대안 (Alternatives)

| 대안 | 기각 사유 |
| --- | --- |
| 인라인 토큰을 에디터 모드에 열기 | 토큰은 문서 모델에 붙어 원문 편집과 따로 맞춰야 하고, 토큰 안은 고칠 수 없다. 앱이 쓰지 않는 경로(터치 캐럿 등)까지 에디터 모드에 맞춰야 한다 |
| 할 일 줄을 접고(ADR-0008) 줄 블록에 체크 상자와 글을 앱이 그리기 | 앱이 글자를 따로 그려 서체·줄바꿈이 에디터와 달라지고, 커서가 들어갈 때 배치가 바뀌어 글이 밀린다 |
| 기호 글자를 체크 상자 모양 글자(☐)로 바꿔 저장 | 표준 GFM이 아니게 된다 |
| 단축키로만 체크하기 | 체크 상자가 보이지 않는다. 오버레이와 함께 둘 수 있으므로 후속 작업으로 남긴다 |
