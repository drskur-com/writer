# ADR-0012: 시트 접합은 파일을 합치지 않고 그룹 메타 `glued`에 "앞 시트에 이어짐"으로 적는다

- 상태: Proposed (이동 규칙은 ADR-0014로 일부 Superseded)
- 날짜: 2026-10-20
- 갱신: 2026-10-21
- 대체: 이동 단위·드래그 미리보기·놓일 자리 표시 규칙은 [ADR-0014](./0014-individual-sheet-move-glue.md)를 따른다. 아래의 묶음 단위 이동은 이전 결정이다.
- 관련: ADR-0005, ADR-0013, `docs/benchmark/ulysses.md` §2(시트 붙이기 A안) · `src/library/meta.rs`, `src/app/sheet_list.rs`, `src/export/mod.rs`

## 배경 (Context)

여러 시트를 하나로 묶어(예: 장 하나를 여러 시트로 나눠 쓴 것) 프리뷰·내보내기에서 이어지게 하고, 다시 풀 수도 있어야 한다.
Ulysses의 Glue는 시트 내용을 실제로 한 시트로 합친다. 합친 뒤 되돌리려면 원문 안에 경계를 남기거나 직접 잘라야 한다.

## 결정 (Decision)

**시트 파일은 그대로 두고, 그룹 `.writer.toml`의 `glued`에 앞 시트에 접합한 시트의 파일명을 적는다.**

- 뜻: 수동 순서에서 `glued`에 있는 시트는 바로 앞 시트에 이어진다. 그룹의 첫 시트는 접합할 수 없다.
- 시트 목록에서 Shift+클릭으로 연 시트부터 누른 시트까지 고르고, 우클릭 메뉴에서
  - **시트 접합**: 고른 시트의 첫 시트 뒤를 모두 앞 시트에 접합한다(둘 이상, 아직 다 이어지지 않았을 때).
  - **접합 해제**: 고른 시트(누른 시트가 선택 밖이면 그 시트만)를 앞뒤 시트에서 떼어 낸다. 범위의 시트와 범위 바로 뒤 시트의 접합을 푼다.
- 접합은 수동 순서 그룹(프로젝트 원고, 수동 정렬 그룹)에서만 한다. 다른 정렬·"모두"에서는 표시도 메뉴도 쓰지 않는다.
- 접합할 때 지금 순서를 `sheets`에도 적는다. 순서가 정해지지 않은 시트는 수정할 때마다 자리가 바뀌어 이웃이 달라질 수 있어서다.
- 접합한 시트는 묶음째 옮긴다(묶음의 어느 시트를 끌어도). 놓는 자리가 다른 묶음이면 그 묶음 앞(위로)이나 뒤(아래로)에 놓아 묶음을 가르지 않는다. 같은 묶음 안에 놓으면 그대로 둔다. 그래서 옮겨도 접합은 바뀌지 않는다.
- 목록에서는 접합한 시트를 왼쪽 선으로 잇고 사이 구분선을 지운다.
- 끄는 동안 미리보기는 묶음 전체다(시트 이름을 이어 붙이고 왼쪽 선으로 잇는다, 5개를 넘으면 "외 N개 시트"). 놓일 자리 표시는 대상 묶음의 가장자리에만 보인다(접합한 시트 사이에는 없다).
- 미리보기·컴파일에서는 접합 여부를 시트 경계에 반영한다. 접합한 시트는 앞 시트에 이어지고, 접합하지 않은 시트는 새 페이지 또는 새 XHTML 섹션에서 시작한다. 제목의 별도 페이지·페이지 나눔 설정은 따로 적용된다.

### 선택 범위에 대한 추가 결정 (2026-10-21)

에디터의 미리보기와 컴파일은 같은 범위 계산(`export::load_selection`)을 쓴다. 선택한 시트에 따라 접합 묶음의 일부가 빠지거나 두 기능의 대상이 달라지는 것을 막기 위해서다.

- 단일 시트: 접합하지 않은 시트는 자기 하나, 접합한 시트는 앞뒤로 이어진 접합 묶음 전체를 포함한다. 묶음 중간이나 마지막 시트를 눌러도 같다.
- 복수 시트: Shift+클릭으로 선택한 시트를 목록의 선택 순서대로 처리한다. 각 시트를 접합 묶음으로 확장하고, 이미 포함한 시트는 다시 넣지 않는다. 묶음 내부는 그룹의 수동 순서를 따른다.
- 그룹: 해당 그룹의 시트와 하위 그룹의 시트를 원고 순서로 포함한다. 그룹의 첫 시트는 앞 그룹의 시트와 접합하지 않는다.
- 복수 선택으로 하나의 미리보기·파일에 포함하는 것만으로 접합 상태를 바꾸지는 않는다. 서로 접합하지 않은 시트 사이의 경계는 유지한다.
- 프로젝트 패널의 미리보기·컴파일은 프로젝트 전체를 대상으로 한다. 에디터의 선택 범위 규칙과 구분한다(ADR-0013).

```toml
sheets = ["a.md", "b.md", "c.md"]
glued = ["b.md", "c.md"]   # b는 a에, c는 b에 이어진다
```

## 결과 (Consequences)

- (+): 해제하면 완전히 되돌아간다. 원문에 경계 표시가 남지 않고, 다른 편집기로 열어도 시트가 그대로다.
- (+): 메타 한 줄이라 동기화 충돌이 작다.
- (+): 미리보기·컴파일에서 접합 묶음 전체를 포함하고, 복수 선택으로 같은 묶음을 여러 번 골라도 시트가 중복되지 않는다.
- (-): 에디터는 지금 한 시트씩 연다. 접합한 시트를 이어서 편집하는 화면은 없다.

## 대안 (Alternatives)

| 대안 | 기각 사유 |
| --- | --- |
| Ulysses처럼 파일을 하나로 합침 | 해제하려면 원문에 경계를 남겨야 하고, 나머지 파일을 지워야 한다 |
| 시트 frontmatter에 플래그 | 순서·이웃은 그룹이 정하므로 그룹 메타가 맞다. 시트 원문을 건드리게 된다 |
| 접합 묶음 id(`[[glue]] sheets = [...]`) | 순서와 따로 관리해야 해서 이동·삭제 때 맞추기가 더 어렵다 |
