# ADR-0036: 문단 안의 `{{name key=value}}`는 에디터에서 원자 단위 인라인 객체로 보이고, 내보내기에서는 확장의 글로 바뀐다

- 상태: Proposed
- 날짜: 2026-10-23
- 관련: ADR-0026(Lua 확장), ADR-0032(호버·클릭), ADR-0033(편집 대화상자), ADR-0034(`export:`), ADR-0010(줄 배치) · `src/extension/mod.rs`(`inline_calls`, `inline_text`, `Extension::value`, `resolve_inline`), `src/app/editor_extension.rs`(`inline_tokens`, `render_inline`), `vendor/gpui-base/src/input/editor/writer.rs`(`set_inline_objects`), `docs/patches/gpui-base-0.8.0-inline-objects.patch`

## 배경 (Context)

확장은 블록(`` ```ext ``)으로만 쓸 수 있었다. 오늘 날짜(`{{today}}`), 진행률 같은 작은 그림, 작은 버튼처럼 문단 안에 끼는
것이 필요하다. 보이는 글은 원문 `{{today}}`와 폭이 달라서 할 일 체크 상자의 줄 오버레이(덮는 글과 같은 폭)로는 그릴 수 없다.
gpui-base에는 원문과 다른 글을 보이는 원자 단위 인라인 토큰(`InlineToken`: 폭 측정·줄바꿈·커서·삭제·선택·복사)이 있지만,
코드 에디터 모드에서는 꺼져 있고 토큰 행이 우리 줄 배치(제목 확대·정렬·들여쓰기·줄 블록)를 거치지 않는다.

## 결정 (Decision)

**원고 원문은 `{{name key=value}}` 그대로 두고, 에디터는 그것을 원문에서 그때그때 찾은 원자 단위 객체로 보인다. 원문은 커서가
들어와도 보이지 않고, 인자는 편집 대화상자로 고친다. 내보내기는 확장의 글로 바꾼다.**

- 표기: `{{` 이름(글자로 시작하는 확장 이름) 인자들 `}}`. 인자는 `key=value`, 빈칸·`"`·`{`·`}`가 있는 값은 `"…"`(`\"`). 인라인 코드 안은
  글자다. 이름 꼴이 아니면(`{{ 3 }}`) 확장이 아니다.
- 확장: `value(args, ctx)`가 있으면 그 글(`ctx.sheet`)을 보인다. 없고 `draw`가 있으면 캔버스를 줄 높이로 줄여 보인다(영역·`click`도 된다.
  누른 결과는 그 원문에 쓴다).
- gpui-base(`set_inline_objects`): 앱이 준 함수가 줄마다 객체 범위와 토큰을 찾는다. 문서·되돌리기 기록에는 넣지 않는 **파생 토큰**이다.
  - 편집 직후에는 겹친 객체를 빼고 뒤 객체를 민다. 다음 배치 전에 문서 전체에서 다시 찾는다(IME 조합 중인 범위는 뺀다).
  - 커서·삭제·선택·복사는 기존 토큰 엔진을 그대로 쓴다(원자 단위, 복사는 원문).
  - 객체 렌더러는 따로 둔다. 스타일 뷰(`Input`)가 그릴 때마다 토큰 표현을 다시 깔기 때문이다.
  - 행 배치: 객체가 있는 행은 글자 조각과 객체 자리(측정한 폭)로 만들고, 줄 스타일(글자 크기·행 높이·첫 줄 들여쓰기·정렬·줄 블록·
    접힌 줄)을 그대로 적용한다. 양쪽 정렬은 객체가 없는 행만 늘인다.
  - 줄바꿈: 객체는 쪼개지 않는 고정 폭으로 재고(`measured_wrap_boundaries_with`), 글자 크기와 첫 줄 들여쓰기를 지킨다.
  - 줄 오버레이는 객체와 겹치면 그리지 않고, 접힌 줄의 객체는 그리지 않는다.
- 에디터: 글은 작은 칩, 그림은 캔버스. 고른 객체는 배경으로 보인다. 누르면 객체를 고르고, 두 번 누르거나 ⌘와 누르면 편집 대화상자
  (인라인 모드: 배율·자리 없음, 원문 편집, 글은 미리보기 자리에 크게)를 연다. 글은 1분까지 캐시하고 글·확장이 바뀌면 다시 묻는다.
- 내보내기·책 미리보기: 파싱 뒤 `resolve_inline`이 `{{…}}`를 확장의 글로 바꾼다. `export:`·확장의 `export`로 빼는 것과 그림은 지운다.
  확장을 읽지 못하면 원문 그대로 둔다.
- 어시스턴트: `run_extension`이 `value`가 돌려준 글을 알린다. 스킬 `references/inline.md`, 예제 `today`.

## 결과 (Consequences)

- (+): 원고는 평범한 마크다운이다. 다른 앱에서는 `{{today}}` 글자로 보이고, 복사·붙여넣기·되돌리기가 원문 기준이라 단순하다.
- (+): gpui-base의 토큰 엔진을 다시 써서 커서·선택·IME 처리가 Input·Textarea와 같다. gpui-base 테스트 1450개가 통과한다.
- (-): 인라인 그림은 아직 내보내지 않는다(미리보기·PDF는 줄 안 그림 배치, ePub·DOCX는 인라인 이미지가 필요하다).
- (-): 객체가 있는 행은 양쪽 정렬로 늘이지 않는다. 객체 높이는 기본 줄 높이라 확대한 제목 안에서는 작게 보인다.
- (-): 편집마다 문서 전체에서 객체를 다시 찾고, 판 수가 바뀌면 보이는 객체를 모두 다시 잰다(긴 문서·많은 객체에서 비용).
- (-): 객체 요소의 id가 문서 위치를 쓰므로, 앞에서 고치면 인라인 위젯의 호버 상태가 처음으로 돌아간다. 되돌리기 뒤 커서가 객체
  안쪽에 남을 수 있다(다음 이동에서 경계로 간다).
- (-): `{{today}}` 같은 글은 최대 1분 늦게 바뀐다.
