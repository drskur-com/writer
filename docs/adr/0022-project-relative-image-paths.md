# ADR-0022: 프로젝트 시트의 이미지 경로는 프로젝트 폴더 기준으로 적는다

- 상태: Proposed
- 날짜: 2026-10-22
- 관련: ADR-0007(이미지 속성), ADR-0019·ADR-0020(그룹 간 이동), ADR-0021(경로 해석) · `src/library/images.rs`, `src/library/book.rs`, `src/app/insert_image.rs`

## 배경 (Context)

이미지를 넣으면 첨부파일 그룹(`<Project>/Extras/Attachments`)에 복사하고, 시트 폴더에서 본
상대 경로(`../../Extras/Attachments/<ULID>.png`)를 마크다운에 적었다.

- 시트나 그룹을 옮기면(ADR-0019·ADR-0020) `../` 깊이가 어긋나 그림이 깨진다. ADR-0021은 어긋난
  경로를 위 폴더에서 다시 찾아 증상을 덮었지만, 원인(경로가 시트 위치에 묶임)은 그대로다.
- 첨부파일은 언제나 프로젝트 안의 한 곳에 있다. 시트가 어디 있든 그림의 위치는 같다.
- 절대 경로는 라이브러리를 옮기거나 다른 Mac(iCloud 등)·`.writer` 내보내기에서 열면 깨진다.

## 결정 (Decision)

**프로젝트 시트에 넣는 이미지는 프로젝트 폴더 기준 경로(`Extras/Attachments/<ULID>.png`)로 적는다.**

- `library::add_attachment`·`library::attach_bytes`가 프로젝트 기준 경로를 돌려주고, 이미지 삽입
  대화상자는 그 경로를 그대로 쓴다. 시트 기준 경로를 만들던 `attach_to_sheet`는 없앤다.
- `resolve_image_path`는 시트 폴더 → 프로젝트 폴더 → 첨부파일 그룹 순으로 찾는다. 에디터·미리보기
  처럼 프로젝트 폴더를 넘기지 않으면, 시트 폴더가 `<라이브러리>/Projects/<프로젝트>` 안일 때 그
  프로젝트 폴더를 쓴다.
- 첨부파일 그룹은 하위 폴더로 나누지 않고 한 폴더에 둔다. 파일 이름이 ULID라 겹치지 않고,
  APFS는 한 폴더의 파일 수가 많아도 이름으로 찾는 비용이 거의 늘지 않는다. 경로가 마크다운에
  적히므로 나중에 나누면 원고를 고쳐 써야 한다. 그래서 처음부터 나누지 않기로 정한다.
- 프로젝트 기준 후보에는 `..`가 든 경로를 쓰지 않는다(프로젝트 밖으로 나가지 않는다).
- 예전에 넣은 시트 기준 경로는 고쳐 쓰지 않는다. ADR-0021의 다시 찾기로 계속 열린다.
- 메모(프로젝트 밖)는 이번 결정에 넣지 않는다. 메모의 첨부 위치는 ADR-0041(`Notes/Attachments`,
  `Notes/` 기준 경로)이 정한다.

## 결과 (Consequences)

- (+): 시트·그룹을 옮겨도, Finder에서 옮겨도 경로가 바뀌지 않는다. 옮길 때 원고를 고쳐 쓸 필요가 없다.
- (+): ADR-0007의 예시(`![캡션](Extras/Attachments/…)`)와 같은 모양이 된다.
- (-): 다른 마크다운 편집기에서 시트만 열면 그림이 보이지 않는다. Pandoc은 `--resource-path`에
  프로젝트 폴더를 주면 찾는다.
- (-): 첨부파일이 수천 개를 넘으면 그룹 읽기(`scan_files`), 수동 정렬 순서(`files` 메타), 이미지
  삽입 대화상자의 썸네일 목록(가상 스크롤 아님)이 느려진다. 폴더를 나눠도 해결되지 않으므로 필요해지면
  화면 쪽(가상 스크롤·보이는 썸네일만 그리기·검색)을 고친다.
- (-): 한 원고에 시트 기준(옛)·프로젝트 기준(새) 경로가 섞인다. 둘 다 열리지만, 필요하면 한 번에
  바꾸는 명령을 따로 둔다.

## 대안 (Alternatives)

| 대안 | 기각 사유 |
| --- | --- |
| 절대 경로 | 라이브러리 이동·다른 기기·`.writer` 내보내기에서 깨진다. 원고에 사용자 폴더 이름이 남는다 |
| 시트 기준 경로를 두고 옮길 때 `../`를 고쳐 쓰기 | 그룹 이동 때 하위 시트를 모두 고쳐 써야 하고, 이동 되돌리기(ADR-0019·0020)에 파일 내용까지 넣어야 한다. Finder로 옮기면 여전히 깨진다 |
| 첨부파일을 하위 폴더로 나누기(`Attachments/A/…`) | ULID 앞자리는 시각이라 지금 만드는 이름이 모두 `01`로 시작해 고르게 나뉘지 않는다. 무작위 끝자리로 나누면 사람이 폴더를 볼 때 의미가 없다. 느려지는 곳은 파일 시스템이 아니라 앱 화면이다 |
| 앱 고유 스킴(`attachment:<ULID>.png`) | 어떤 도구도 읽지 못한다. 프로젝트 기준 경로는 적어도 Pandoc·사람이 따라갈 수 있다 |
